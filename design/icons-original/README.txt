NoirWatchFace SVG Icons

Contents:
- resources/images/*.svg : all health and weather icons in SVG
- resources/drawables/noir_icons.xml : bitmap resource mapping for Garmin

Health colors:
- heart.svg      -> #DE858B
- bolt.svg       -> #A9BEDD
- steps.svg / footsteps.svg -> #79BFB7

Weather icons use a light gray/white stroke suitable for a dark watch face.

To use them, replace the corresponding files in your project and keep the same filenames expected by the code.
